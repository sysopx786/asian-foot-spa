## What is offered

Each service page says what the work is, what to expect, who it fits, and when to skip it. It does not diagnose illness and it is not medical care.

Short definitions used on the site:

- **Foot reflexology.** Thumb and finger pressure on mapped points of the soles, arches, heels, balls of the feet, and toes. The work stays on the feet.
- **Swedish.** Oil or lotion, with gliding, kneading, friction, tapping, and vibration. Pressure is light to moderate. The guest is draped.
- **Deep tissue.** Slow, sustained pressure into deeper muscle and fascia. Firm is not the same as painful. It is not physical therapy.
- **Shiatsu.** Japanese finger-pressure along meridians. Usually clothed, usually without oil.
- **Thai.** Pressure along sen lines, plus assisted stretches. Usually clothed, without oil, and more active than lying still.
- **Hot stone.** Heated stones placed on the body or held in the hand. They should feel warm, not burning. The guest can refuse them.
- **Aromatherapy.** Essential oil diluted in a carrier oil, applied during a massage. The method is still the massage. Scent is optional.
- **Couples.** Two people booked at the same time. Each person receives a massage. It is a way of booking, not a different technique.
- **Cupping.** Cups on the skin create suction and lift the tissue. Marks can last a few days. It is not a gliding massage stroke.

## What the homepage contains

Sticky black header with the sign, the menu, the language switch, and today’s open or closed line. Then the studio introduction, the walkthrough, the rooms, the full posted menu with the cash-versus-card table, accessibility and payments, the Google review summary, and the FAQ.

## Stack

React 19, TanStack Start, Vite, Tailwind CSS v4.

GitHub Pages is published from `main` by [`.github/workflows/pages.yml`](.github/workflows/pages.yml). A push to `main` builds the site with `GITHUB_PAGES=1`, prerenders the English, Spanish, and Chinese routes, and copies `public/media` into the Pages artifact. Photo addresses use the `/asian-foot-spa/` prefix.

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:8080](http://localhost:8080).

```bash
npm run build
npm run preview
```
